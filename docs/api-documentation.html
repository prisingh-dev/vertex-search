Vertex AI Retail Search API
REST API exposing Google Cloud Vertex AI Retail capabilities — enabling intelligent product search and real-time typeahead autocomplete for e-commerce applications.
POST /api/v1/search
Full-text product search against the Vertex AI Retail catalog. Supports keyword ranking, faceting, sorting, filtering, and store-scoped results.
GET /api/v1/autocomplete
Real-time typeahead suggestions powered by Vertex AI Retail Completion. Returns ranked suggestions as the user types.

Technology Stack

Authentication

All requests to live endpoints are authenticated via Google Cloud identity. The API uses Application Default Credentials (ADC) — credentials are resolved once at service startup and shared across all requests.
Developer / Workstation

Authenticate using the Google Cloud CLI:

gcloud auth application-default login

Credentials are stored locally and automatically resolved by the SDK.

Production / GCP Infrastructure

On Cloud Run, GKE, or Compute Engine, the attached Service Account is used automatically — no credential files required.

⚑
Required IAM RoleAssign roles/retail.viewer (minimum read access) to the service account.
ℹ
No API Key Required Authentication is handled at the infrastructure level via GCP identity. Client applications call this REST API directly — they do not interact with Google Cloud credentials.

Architecture

The API is built on a chain-of-responsibility pipeline pattern. Each request passes through a fixed sequence of steps — validation, request translation, GCP invocation, and response translation — before the result is returned to the caller.
Layer 1 — Gateway

Controller

Receives the HTTP request, enforces content negotiation, delegates to the pipeline, and serialises the final response as JSON.

Layer 2 — Pipeline

Step Chain

Ordered sequence of discrete steps: validate inputs, translate to GCP format, invoke Google Cloud, translate the response back.

Layer 3 — GCP

Vertex AI Retail

Google-managed search and completion services accessed via gRPC. Two dedicated SDK clients — one per service — maintained as application singletons.

POST /api/v1/search ● Production
Executes a full-text keyword search against the Vertex AI Retail product catalog. Returns a ranked list of matching products alongside facet aggregations, pagination statistics, and contextual metadata.

Request

Request Body Content-Type: application/json
Field Type Required Description
query string Required The search term entered by the user. Must be non-empty.
visitorId string Required Unique visitor or session identifier. Used by Vertex AI for personalisation and analytics attribution. Typically a cookie or device ID.
pageSize integer Optional Number of products to return per page. Default: 20. Range: 1–100.
offset integer Optional Zero-based index of the first result to return. Used for offset pagination. Default: 0. Ignored when pageToken is provided.
pageToken string Optional Cursor token for page-based pagination. Use the nextPageToken from the previous response to fetch the next page. When provided, offset is ignored.
orderBy string Optional Sort order alias. Accepted values: relevance, price_low_to_high, price_high_to_low, newest. Defaults to relevance ranking.
filter string Optional Vertex AI Retail filter expression applied to the result set. Example: availability: IN_STOCK.
facetKeys string[] Optional List of facet dimension aliases to return with the response. Accepted values: color, size, brand, category, price.
queryExpansionCondition string Optional Controls Vertex AI query expansion behaviour. AUTO allows the engine to broaden the query when few results are found. DISABLED enforces strict matching. Default: AUTO.
storeId string Optional Store identifier used to scope search results to a specific physical location. Maps to PlaceId in the Vertex AI Retail API. When omitted, results are returned from the full catalog.
Request Example — First Page
// POST /api/v1/search
// Content-Type: application/json

{
  "query": "red running shoes",
  "visitorId": "session-a1b2c3",
  "pageSize": 20,
  "offset": 0,                          // offset-based pagination
  "orderBy": "price_low_to_high",
  "filter": "availability: IN_STOCK",
  "facetKeys": ["color", "brand", "size"],
  "queryExpansionCondition": "AUTO",
  "storeId": "store-042"               // optional — scope to specific store
}
Request Example — Next Page (cursor)
// Use pageToken returned in the previous response to fetch the next page.
// When pageToken is set, offset is ignored.

{
  "query": "red running shoes",
  "visitorId": "session-a1b2c3",
  "pageSize": 20,
  "pageToken": "eyJwYWdlIjogMn0..."  // nextPageToken from previous response
}

Response — 200 OK

Response Fields
FieldTypeDescription
productsProductResult[]Ranked list of matching products for the current page.
facetsFacetResult[]Facet aggregations for the requested facetKeys. Absent when no facet keys were requested.
statsSearchStatsPage and total result counts.

correctedQuerystringSpell-corrected query used by Vertex AI, if the original query contained a typo. Absent when no correction was applied.
attributionTokenstringOpaque token for analytics attribution. Include in downstream analytics events.
redirectUristringRedirect URL if a Vertex AI search rule triggered a redirect. Absent when no redirect applies.
appliedControlsstring[]Names of Vertex AI serving controls (boost, bury, filter rules) applied to this request.

ℹ
Store-Scoped Search Optional. An id corresponding to a place, such as a store id or region id. When specified, we use the price from the local inventory with the matching product's LocalInventory.place_id for revenue optimization.

Response Status Codes

200 OK Search completed successfully. Results returned in body.
400 Bad Request Missing or invalid field — query, visitorId, pageSize out of range, or malformed JSON body.
401 Unauthorized The service's GCP credentials are missing or expired.
403 Forbidden The service account does not have the required IAM permissions on the Retail catalog.
404 Not Found The configured catalog, branch, or serving config does not exist in the GCP project.
429 Too Many Requests Vertex AI Retail API quota has been exceeded.
503 Service Unavailable Vertex AI Retail Search is unavailable or the gRPC call failed.
GET /api/v1/autocomplete ● New
Returns typeahead completion suggestions from the Vertex AI Retail Completion service. Designed to be called on each keystroke as the user types a search query, enabling instant suggestion dropdowns. The query is automatically normalised to lowercase before being sent to Google Cloud.

Query Parameters

Parameter Type Required Description
query string Required The partial search term to complete. Automatically converted to lowercase before being forwarded to Vertex AI, ensuring case-insensitive suggestion matching.
visitorId string Required Unique visitor or session identifier. Used by Vertex AI for personalised suggestion ranking and analytics.
maxSuggestions integer Optional Maximum number of suggestions to return. Default: 10. Range: 1–20.
Request Example
// GET /api/v1/autocomplete
?query=running
&visitorId=session-a1b2c3
&maxSuggestions=5

// Full URL example:
GET /api/v1/autocomplete?query=running&visitorId=session-a1b2c3&maxSuggestions=5
ℹ
Query Normalisation The value of query is automatically converted to lowercase before being sent to Vertex AI. This ensures that "Running", "RUNNING", and "running" all return the same suggestions. The original casing sent by the client does not affect results.

Response — 200 OK

Response Example
{
  "suggestions": [
    { "suggestion": "running shoes" },
    { "suggestion": "running tights" },
    { "suggestion": "running jacket" },
    { "suggestion": "running socks" },
    { "suggestion": "running shorts" }
  ],
  "attributionToken": "AHRlcnJpZmljLXRva2Vu..."
}
ℹ
Attribution Token When a user selects a suggestion and proceeds to a full search, include the attributionToken from the autocomplete response in the subsequent search event. This informs Vertex AI that the search originated from a completion suggestion, enabling improved ranking and analytics reporting.

Response Status Codes

200 OK Suggestions returned successfully. May return an empty suggestions array if no matches are found.
400 Bad Request Missing query or visitorId, or maxSuggestions is outside the range 1–20.
401 Unauthorized The service's GCP credentials are missing or expired.
403 Forbidden The service account does not have the required permissions on the Retail catalog.
503 Service Unavailable Vertex AI Retail Completion service is unavailable or the gRPC call failed.

Configuration

The service is configured via appsettings.json. All values can be overridden at deployment time using environment variables with the double-underscore separator convention (e.g. Gcp__ProjectId=my-project).

GCP Settings

Gcp:ProjectId— (required)Google Cloud project ID hosting the Retail catalog.
Gcp:Retail:LocationglobalVertex AI Retail region.
Gcp:Retail:Catalogsdefault_catalogName of the product catalog.
Gcp:Retail:Branchdefault_branchCatalog branch (analogous to a version or environment).

Error Reference

All error responses share a consistent JSON structure. Client applications should handle errors by inspecting the HTTP status code, then reading the error field for a human-readable description.

Error Response Format

Error Response
// HTTP 400 Bad Request (example)
{
  "error": "query is required"
}

// HTTP 503 Service Unavailable (example)
{
  "error": "Failed to fetch autocomplete suggestions"
}

Status Code Reference

200 OK Request processed successfully.
400 Bad Request Request validation failed. Check the error field for the specific field and constraint that failed.
401 Unauthorized The service's Google Cloud credentials are absent or have expired. Contact the infrastructure team.
403 Forbidden The service account lacks the required IAM role (roles/retail.viewer) on the GCP project.
404 Not Found The GCP catalog, branch, or serving configuration referenced in appsettings.json does not exist.
429 Too Many Requests The Vertex AI Retail API quota for this GCP project has been exceeded.
500 Internal Server Error An unexpected error occurred within the service.
503 Service Unavailable Vertex AI Retail Search or Completion is temporarily unavailable. The gRPC call to Google Cloud failed.
⚑
4xx vs 5xx HTTP 4xx errors indicate a problem with the request or service configuration that requires action. HTTP 5xx errors indicate a transient downstream failure — these are safe to retry with exponential back-off.
